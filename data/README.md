# Data

This project needs no external data.

- The benchmark functions (Sphere, Rastrigin, Ackley, Rosenbrock) are written in code in `src/`.
- The feature-selection experiment uses the breast cancer dataset that ships with
  scikit-learn (`sklearn.datasets.load_breast_cancer`), so nothing has to be downloaded.

Files in this folder (except this README) are ignored by Git.
